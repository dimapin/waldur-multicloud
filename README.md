# waldur-multicloud

> **EXPERIMENT** — Öffentlicher Versuch zu Multi-Cloud-Management mit
> [Waldur](https://waldur.com) Site-Agent-Plugins (Hetzner, Proxmox,
> IONOS; später STACKIT), entwickelt in einem Multi-Agenten-Workflow
> mit Claude Code. Fortführung ist nicht entschieden. Keine
> Produktionsnutzung. Community-Projekt — nicht mit Waldur/OpenNode
> affiliiert.

Meta-Repo: Interface-Contract, Testkit (Contract-Tests), kanonische
Agenten-Rollen, Workflow-Doku, Demo-Deployment. Provider-Code liegt in
den Repos `waldur-site-agent-{hcloud,proxmox,ionos}`.
